The `DirectionProvider` sets the text direction (`ltr` or `rtl`) that Base UI's components read, for right-to-left languages like Arabic, Hebrew and Persian. Set `dir` on the matching element too, so the browser lays the content out in that direction.

## Usage

```tsx
import { DirectionProvider } from "@/components/ui/direction"
```

```tsx
<html dir="rtl">
  <body>
    <DirectionProvider direction="rtl">
      {/* Your app content */}
    </DirectionProvider>
  </body>
</html>
```

## useDirection

The `useDirection` hook returns the current direction.

```tsx
import { useDirection } from "@/components/ui/direction"

function MyComponent() {
  const direction = useDirection()
  return <div>Current direction: {direction}</div>
}
```

## API Reference

Direction re-exports Base UI's [Direction Provider](https://base-ui.com/react/utils/direction-provider#api-reference) (`direction`: `ltr` · `rtl`, default `ltr`).
