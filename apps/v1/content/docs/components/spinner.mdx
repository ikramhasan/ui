## Usage

```tsx
import { Spinner } from "@/components/ui/spinner"
```

```tsx
<Spinner />
```

Eight spokes, each a step brighter, turn in eight ticks. Reduced motion halves the speed rather than stopping it, since the spinner is the only sign that work is happening.

## API Reference

`Spinner` renders an `svg` with `role="status"` and `aria-label="Loading"`, and accepts all of its props.
