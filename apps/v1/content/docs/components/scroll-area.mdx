## Usage

```tsx
import { ScrollArea, ScrollBar } from "@/components/ui/scroll-area"
```

```tsx
<ScrollArea className="h-[200px] w-[350px] rounded-lg border p-4">
  Your scrollable content here.
</ScrollArea>
```

The scrollbar is a 6px thumb in a 10px track, in `muted-foreground` at 50% like the menus' scrollbars. It widens to 8px and darkens while you hover or drag it. The track sits inside the border, and its round ends clear corners up to `rounded-lg`. For a rounder container, inset the bar with `className` (e.g. `data-vertical:py-2`).

## Composition

Use the following composition to build a `ScrollArea`:

```text
ScrollArea
└── ScrollBar
```

## API Reference

`ScrollArea` wraps Base UI's `ScrollArea.Root` (`data-slot="scroll-area"`), with a `Viewport` (`scroll-area-viewport`), a vertical `ScrollBar` and a `Corner` inside it. `ScrollBar` wraps `ScrollArea.Scrollbar` (`scroll-area-scrollbar`) and its `Thumb` (`scroll-area-thumb`) and takes `orientation` (`"vertical"` by default, or `"horizontal"`).

See the [Base UI Scroll Area](https://base-ui.com/react/components/scroll-area#api-reference) documentation for every prop.
