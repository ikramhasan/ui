## Accessibility

- Streaming or progress markers ("Thinking…", a running tool) take `role="status"`.
- A labeled separator needs no role: the lines are decorative pseudo-elements and the label reads as text. Don't add `role="separator"`, which would hide the label.
- `MarkerIcon` is `aria-hidden`; give an icon-only marker an `aria-label`.
- Interactive markers are real `<a>` or `<button>` elements via `render`.

## API Reference

| Part            | Element | Props / notes                                                                                                                     |
| --------------- | ------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `Marker`        | `div`   | `variant`: `default` · `border` · `separator` (default `default`). `render` to use a different element. Also exports `markerVariants`. |
| `MarkerIcon`    | `span`  | A decorative 16px icon slot, hidden from assistive tech.                                                                          |
| `MarkerContent` | `span`  | The marker text.                                                                                                                  |
