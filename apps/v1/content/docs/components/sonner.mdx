## About

Sonner is built and maintained by [emilkowalski](https://twitter.com/emilkowalski). This component restyles its toasts: the message sits on a raised card inside a muted shell, and the buttons sit on the shell beside it.

## API Reference

See the [Sonner API reference](https://sonner.emilkowal.ski/getting-started) for every option of `Toaster` and `toast()`. `Toaster` accepts all of Sonner's props; any `toastOptions.classNames` you pass are merged with the built-in ones.
