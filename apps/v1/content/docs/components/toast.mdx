## About

Toast is built on Base UI's [Toast](https://base-ui.com/react/components/toast). It shares the [Sonner](/docs/components/sonner) look: the message sits on a raised card inside a muted shell, and the action and close buttons sit on the shell beside it.

## Usage

```tsx
import { toast } from "@/components/ui/toast"
```

```tsx
toast.add({
  title: "Event created",
  description: "Sunday, December 3 at 9:00 AM",
})
```

## Examples

### Types

Set the `type` option to show a status icon: `success`, `info`, `warning`, `error` and `loading`.

<ComponentPreview name="toast-types" />

### Action

Use `actionProps` to add an action button.

```tsx
const id = toast.add({
  title: "Event created",
  actionProps: {
    children: "Undo",
    onClick() {
      toast.close(id)
    },
  },
})
```

### Promise

Use `toast.promise` to follow an async task from loading to success or error.

<ComponentPreview name="toast-promise" />

## API Reference

`toast` is a manager from Base UI's `createToastManager()`: `add`, `close`, `update` and `promise`. `Toaster` takes every [Toast.Provider](https://base-ui.com/react/components/toast#provider) prop (`limit`, `timeout`, `toastManager`, …). The parts (`Toast`, `ToastContent`, `ToastTitle`, `ToastDescription`, `ToastAction`, `ToastClose`, `ToastViewport`, `ToastPortal`, `ToastProvider`) and `useToastManager` are exported for custom layouts.
